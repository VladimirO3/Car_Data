1. Project Overview

TrackLit is a professional-grade GPS trip tracker for Android. It automates mileage tracking, records peak speeds, and calculates real-time fuel consumption with seasonal adjustments. The app is optimized for high accuracy and reliable background operation.

  • High-sensitivity GPS tracking (2-meter threshold for drift filtering).
  • Dynamic fuel calculation with additive seasonal factors (+10% Winter, +10% Spring).
  • Real-time peak speed recording (integer precision).
  • Background operation via Foreground Service with dynamic notifications (speedometer, trip, speed).
  • In-app OTA updates via Firebase Remote Config.
  • Instant coordinate sharing feature (Google Maps link).
  • System-level compatibility: Bluetooth permissions for power stats polling on Android 15+.

2. Architecture

The project follows the MVVM (Model-View-ViewModel) pattern with Jetpack Compose for the UI layer and a clean separation of concerns.

LayerTechnologyPurpose
UIJetpack ComposeDeclarative, responsive interface (Portrait/Landscape).
LogicKotlin ViewModelCalculations, input validation, and state management.
ServiceForeground ServiceContinuous GPS tracking even when the app is minimized.
StorageSharedPreferencesPersistent storage for mileage, fuel, and speed records.
UpdatesFirebase Remote ConfigCloud-based version control and update alerts.

3. Localization and Languages

The application supports dynamic language switching between Russian and English without restart:

  • Field Labels: Automatic adaptation (Speedometer / Спидометр etc.).
  • Status Indicators: ● TRIP / РЕЙС (Active session badge).
  • System Alerts and Toasts: Full localization of Start/Stop notifications.
  • Background notifications: Text in the notification drawer updates according to the selected language.
UI Layer

4. MainActivity

Handles the Android Lifecycle, permissions logic, and UI rendering.

onCreate()Initializes status receivers, SharedPreferences listeners, and Compose UI.
onStartClicked()Triggers system GPS dialog, checks permissions (including notifications on Android 13+).
toggleLanguage()Toggles the isRussian flag with repository persistence.
shareCurrentLocation()Retrieves coordinates via FusedLocation and shares a Google Maps link.
Business Logic

5. MainViewModel

Manages the application's reactive data stream and mathematical core.

calculateRemainingFuel()Uses traveled distance, fuel rate, and time (idle) to update tank levels.
updateStateFromDistance()Refreshes UI state when the tracker detects a 1-meter movement.
onStartTrip()Locks input fields and resets session-based peak speed.
onStopTrip()Unlocks input fields and performs final data persistence.
Background Service

6. LocationService

Background component ensuring data continuity.

updateNotification()Updates the "live" notification: Speedometer + Trip Distance + Current Speed.
onLocationResult()Filters noise (< 2m) and calculates odometer in real-time.
startForegroundServiceSafe()Starts the service complying with Android 14 requirements (location type).
Storage

7. SettingsRepository

Manages data integrity across app restarts and orientation changes.

saveMaxSpeed()Updates the speed record in persistent storage.
isTripStarted()Retains trip state to allow recovery after device reboot or app crash.
Updates

8. UpdateManager (OTA)

Enables delivery of new APKs without the Google Play Store.

checkForUpdates()Compares server-side latest_version_code with the local app version.
installApk()Leverages FileProvider and intent.ACTION_VIEW to launch the installer.
Diagnostics

9. AppLogger & Sharing

Diagnostic system for tracking GPS accuracy and logic execution.

  • Logs every GPS point, speed update, and fuel calculation.
  • Log Rotation: Prevents file bloat by keeping only the last 500 lines if the size exceeds 1MB.
  • Easy Access: Top-right "Share" icon allows instant export of logs for debugging.

10. Stability & Safety

The app includes several critical safety mechanisms:

  • Input Protection: Fields are disabled during active trips to prevent data corruption.
  • GPS Guard: Force-stops the trip and notifies the user if GPS is disabled during a session.
  • ANR Prevention: Early foreground notification launch in Service's onCreate.
  • System Compatibility: Includes Bluetooth permissions to resolve `BluetoothPowerStatsCollector` errors on Android 15+.
