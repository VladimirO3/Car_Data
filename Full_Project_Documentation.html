1. Обзор проекта

TrackLit — это специализированное Android-приложение для водителей, обеспечивающее автоматизацию учета пробега и расхода ГСМ. Приложение использует GPS для высокоточного измерения дистанции в фоновом режиме и производит динамический расчет остатка топлива с учетом сезонных поправок.

  • Фоновое отслеживание пути через Foreground Service.
  • Фиксация максимальной достигнутой скорости за рейс.
  • Расчет расхода топлива с коэффициентами «Зима» и «Весна» (+10%).
  • Автоматическая остановка рейса при выключении GPS.
  • Система самообновления через Firebase API.
  • Экспорт подробных логов работы программы.

2. Архитектура

Приложение построено на базе современного паттерна MVVM (Model-View-ViewModel) с использованием Jetpack Compose для построения пользовательского интерфейса.

КомпонентРоль
UI Layer (Compose)Декларативное описание интерфейса, реакция на изменения State.
ViewModelУправление состоянием экрана, математические расчеты, валидация ввода.
Service LayerРабота с системными датчиками (GPS) независимо от состояния экрана.
Data LayerОбеспечение постоянного хранения данных (Persistence) через SharedPreferences.
UI Layer

3. MainActivity

Входная точка приложения. Отвечает за разрешения Android, интеграцию с Google Play Services и управление жизненным циклом рейса.

onCreate()Инициализация UI, настройка слушателей изменений данных и проверка статуса GPS.
onStartClicked()Логика проверки GPS и последовательный запрос разрешений (основных и фоновых).
onStopClicked()Остановка фоновой службы и фиксация итоговых данных рейса.
checkBackgroundPermission()Проверка спец. разрешения для Android 10+ на доступ к локации в свернутом режиме.
showGpsRequiredDialog()Критическое уведомление при выключении GPS во время работы.
shareLogFile()Механизм экспорта текстового файла логов через стандартное меню «Поделиться».
Business Logic

4. MainViewModel

Сердце приложения. Содержит всю математическую логику и управляет «реактивностью» интерфейса.

loadFields()Восстановление всех данных из памяти при запуске (спидометр, топливо, норма, рекорд скорости).
calculateRemainingFuel()Алгоритм: baseFuel - (traveledKm * (std * factor) / 100).
onFieldChange()Валидация пользовательского ввода (регулярные выражения, ограничение знаков после запятой).
onStartTrip()Сброс временных счетчиков и фиксация базовых значений одометра перед началом пути.
onStopTrip()Сохранение финальных результатов и перевод интерфейса в режим редактирования.
updateStateFromDistance()Метод, который вызывается при каждом перемещении на 1 метр для обновления цифр на экране.
Background

5. LocationService

Служба, работающая как Foreground Service. Гарантирует, что Android не «убьет» процесс отслеживания при нехватке памяти.

onLocationResult()Фильтрация «дребезга» GPS (порог 1 метр) и расчет скорости по формуле (дистанция/время).
startLocationUpdates()Настройка FusedLocationProvider на высокую точность и интервал обновления 3 секунды.
saveCurrentSpeed()Мгновенная запись скорости в хранилище для немедленного отображения в UI.
Data Persistence

6. SettingsRepository

Обертка над SharedPreferences. Гарантирует сохранность данных даже при полной разрядке устройства.

getTotalDistance()Получение накопленного пробега за текущую сессию.
saveMaxSpeed()Запись рекорда скорости.
getFieldValue()Универсальный метод получения значений по ключам (одометр, топливо).
isTripStarted()Флаг, позволяющий приложению «вспомнить», что рейс не был завершен после перезагрузки.
API Layer

7. UpdateManager

Механизм OTA-обновлений (Over-The-Air) без использования Google Play Store.

checkForUpdates()Запрос параметров latest_version_code и apk_url из Firebase Remote Config.
downloadAndInstallApk()Использование системного DownloadManager для безопасной загрузки файла обновления.
installApk()Запуск интент-фильтра установки пакетов через FileProvider.
Utility

8. AppLogger

Служебный класс для диагностики.

d() / e()Запись логов с временными метками в файл app_logs.txt и в облако Crashlytics.
writeToInternalFile()Метод записи во внутреннюю память с автоматической ротацией (ограничение размера 1МБ).

9. Разрешения (Manifest)

Для корректной работы приложения в AndroidManifest.xml задекларированы следующие доступы:

  • ACCESS_FINE_LOCATION: Точный GPS.
  • ACCESS_BACKGROUND_LOCATION: Работа в фоне.
  • FOREGROUND_SERVICE_LOCATION: Уведомление в шторке при работе.
  • REQUEST_INSTALL_PACKAGES: Установка обновлений.
  • INTERNET: Связь с Firebase.
