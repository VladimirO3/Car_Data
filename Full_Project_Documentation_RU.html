1. Обзор проекта

TrackLit — это профессиональный GPS-трекер рейсов для Android. Приложение автоматизирует учет пробега и рассчитывает расход топлива в реальном времени с учетом сезонных коэффициентов. Оптимизировано для работы в фоновом режиме и высокой точности данных.

  • Высокая чувствительность GPS (порог срабатывания 3 метра для фильтрации дрейфа).
  • Динамический расчет топлива с сезонными надбавками (аддитивно: +10% Зима, +10% Весна, итого до +20%).
  • Интегрированный цифровой компас на базе Rotation Vector Sensor для ориентации в пространстве.
  • Работа через Foreground Service с динамическим уведомлением (спидометр, путь, скорость).
  • Функция мгновенной отправки текущих координат (Google Maps link).
  • Совместимость с Android 15+: Добавлены Bluetooth разрешения для корректного сбора статистики питания системой.
  • Обновленный интерфейс: Использование Material 3 FilledTonalIconButton и группировка кнопок управления.

2. Архитектура

Проект следует паттерну MVVM (Model-View-ViewModel) с использованием Jetpack Compose для UI-слоя.

SensorsSensorManagerОбработка данных датчика вектора вращения для компаса.

3. Локализация и Языки

Приложение поддерживает динамическое переключение языков между Русским и Английским без перезагрузки:

  • Метки полей: Автоматическая адаптация (Speedometer / Спидометр и т.д.).
  • Индикаторы: ● РЕЙС / TRIP (Маркер активного рейса).
  • Системные алерты и Toast-сообщения: Полная локализация уведомлений о старте/стопе.
  • Уведомления в фоне: Текст в шторке уведомлений меняется согласно выбранному языку.
UI Layer

4. MainActivity

Управляет жизненным циклом Android, логикой разрешений и рендерингом UI.

onCreate()Инициализация ресиверов, слушателей SharedPreferences и Compose UI.
onStartClicked()Запуск системного диалога GPS, проверка разрешений (включая уведомления на Android 13+).
toggleLanguage()Переключение флага isRussian с сохранением в репозиторий.
shareCurrentLocation()Получение координат через FusedLocation и отправка ссылки на Google Maps.
Business Logic

5. MainViewModel

Обеспечивает реактивность данных и выполняет математическое ядро приложения.

calculateRemainingFuel()Расчет остатка в баке на основе пути, нормы и времени работы.
updateStateFromDistance()Обновление UI при фиксации перемещения на 1 метр.
onFieldChange()Обновление значений одометра и топлива.
onStartTrip()Блокировка полей ввода.
onStopTrip()Разблокировка полей и фиксация финальных данных в памяти.
Background Service

6. LocationService

Компонент для работы в фоне, обеспечивающий непрерывность данных.

updateNotification()Обновление "живого" уведомления: Спидометр + Пройденный путь + Текущая скорость.
onLocationResult()Фильтрация помех (< 2м) и расчет одометра в реальном времени.
startForegroundServiceSafe()Запуск сервиса с соблюдением требований Android 14 к типам (location).
Storage

7. SettingsRepository

Отвечает за целостность данных при перезагрузке приложения или устройства.

saveMaxSpeed()Сохранение скоростного рекорда в энергонезависимую память.
isTripStarted()Флаг восстановления состояния после сбоя или перезагрузки.
UI Layer

8. Инструкция пользователя

Пошаговое руководство по эксплуатации приложения.

  • Ввод данных: Описание начальной настройки одометра и топлива.
  • Жизненный цикл рейса: Старт, мониторинг в фоне и фиксация итогов.
  • Коэффициенты: Как работают надбавки «Зима» и «Весна».
  • Безопасность: Инструкция по экстренной отправке координат.
Diagnostics

9. AppLogger и экспорт

Система диагностики для отслеживания точности GPS и логики расчетов.

  • Логирование каждой GPS-точки, изменений скорости и расхода.
  • Ротация логов: Автоматическая очистка при достижении размера 1МБ (хранение последних 500 строк).
  • Доступ: Иконка "Share" в верхнем углу для мгновенной отправки логов разработчику.

10. Стабильность и Безопасность

В приложении реализованы критические механизмы защиты:

  • Защита ввода: Поля блокируются во время рейса, чтобы избежать случайного искажения данных.
  • GPS-сторож: Автоматическая остановка рейса с сохранением данных при потере GPS-сигнала.
  • Защита от вылетов: Исправлены ошибки запуска Foreground-сервисов на Android 14+.
  • Тестовое покрытие: 13 модульных тестов, проверяющих логику истории, расчеты топлива и дистанции.
