1. Обзор проекта

TrackLit — это профессиональный GPS-трекер для водителей. В версии 1.5 приложение получило значительное обновление интерфейса, новую систему настроек и улучшенную производительность за счет перехода на внешние навигационные системы.

  • Интерфейс: Динамические приборы (Gauges) с анимацией заполнения.
  • Анимация дыма: Визуальный эффект движения при активном рейсе.
  • Свайп-навигация: Быстрый доступ к картам через жесты.
  • Мультиязычность: Поддержка RU/EN и системного языка.
  • Темы оформления: Поддержка Светлой, Темной и Системной тем.

5. MainViewModel

ViewModel расширена для поддержки новых режимов:

  • languageMode: Хранит выбор языка (0-Система, 1-RU, 2-EN).
  • themeMode: Управляет визуальной темой (0-Система, 1-Light, 2-Dark).
  • toggleTheme() / toggleLanguage(): Циклическое переключение настроек.
Repository

6. SettingsRepository

Обновлен для хранения новых ключей:

  • language_mode: Целое число (режим локализации).
  • theme_mode: Целое число (режим оформления).
  • last_max_speed: Хранение рекорда скорости текущего рейса.
Navigation

7. GPS и Внешняя Навигация

Метод openExternalNavigator() реализует следующую логику:

  1. Получение текущих координат через FusedLocationProvider.
  2. Попытка запуска Яндекс Навигатора.
  3. При неудаче — запуск Яндекс Карт.
  4. В крайнем случае — запуск Google Maps.
