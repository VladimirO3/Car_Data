1. Обзор проекта

TrackLit — это профессиональный GPS-трекер рейсов для Android. Приложение автоматизирует учет пробега и рассчитывает расход топлива в реальном времени. В версии 1.2 реализован новый «автомобильный» интерфейс с имитацией аналоговых датчиков.

  • Интерфейс в стиле приборной панели автомобиля с графическими дугами (Gauges).
  • Единая круглая кнопка управления СТАРТ / СТОП.
  • Интегрированные Яндекс Карты с поддержкой оффлайн-режима и навигацией свайпами (Tabs).
  • Высокая чувствительность GPS (фильтрация дрейфа < 3м).
  • Интегрированный цифровой компас с расчетом азимута возврата.
  • Функция мгновенной отправки текущих координат через Яндекс Источник.
  • История рейсов с возможностью выборочного удаления записей.

2. Архитектура

Проект следует паттерну MVVM (Model-View-ViewModel) с использованием Jetpack Compose.

MapsWebView + Yandex MapsОтображение пробок и местоположения в реальном времени.
ServiceForeground ServiceБесперебойное GPS-отслеживание при свернутом приложении.
StorageSharedPreferencesПостоянное хранение данных и истории поездок.

3. Локализация

Приложение поддерживает Русский и Английский языки:

  • Метки датчиков адаптируются автоматически (ODOMETER / ОДОМЕТР и т.д.).
  • Все системные уведомления и диалоги полностью локализованы.
  • Формат координат и ссылок адаптирован для использования в СНГ (Яндекс Карты).

Background Service

6. LocationService

Foreground Service с типом "location" для Android 14+.

  • Обновление уведомления: Одометр, путь, скорость и курс.
  • Фильтрация помех и расчет дистанции в реальном времени.
  • Автоматическая остановка при критическом отключении GPS.
Storage

7. SettingsRepository

Управляет SharedPreferences:

  • Хранение истории в формате строки с разделителями.
  • deleteTripRecord(): Парсинг и перезапись истории при удалении элемента.
  • Сохранение состояния "Trip Started" для устойчивости к перезагрузкам.
UI Layer

8. Инструкция пользователя

  • Подготовка: Ввод начальных данных в "приборы".
  • Навигация: Свайп в любую сторону для открытия карты.
  • Управление: Центральная красная кнопка для запуска/остановки.
  • Карты: Кнопка "Локация" на карте для перехода в оффлайн-навигатор Яндекса.
Diagnostics

9. AppLogger и диагностика

  • Логирование каждой GPS-точки и системных событий.
  • Кнопка "Share" в истории для отправки отчетов.
  • Автоматическая очистка старых логов.

10. Стабильность

  • Защита WebView: Отключен Autofill для предотвращения NPE (крашей Chromium).
  • Экономия ресурсов: Карта обновляется только при перемещении > 50м.
  • Keep Screen On: Экран не гаснет, пока открыта вкладка навигатора.
