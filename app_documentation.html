Документация приложения TrackLit

Это техническое описание архитектуры, классов и методов Android-приложения для учета пробега и расхода топлива.

MainActivity

UI Layer

Центральная Activity приложения. Управляет жизненным циклом UI (Jetpack Compose), навигацией между экранами и интеграцией с аппаратными датчиками.

Метод / ФункционалОписание
onCreate()Инициализирует UI, регистрирует слушателей настроек и проверяет состояние GPS.
Compass & Return AzimuthИспользует Sensor.TYPE_ROTATION_VECTOR для получения азимута. Рассчитывает обратный курс (+180°).
NavigationОбрабатывает переключение между главным экраном, историей поездок и экраном инструкций.
onStartClicked()Проверяет GPS и разрешения (включая фоновые), затем инициирует запуск рейса.
startTripService()Запускает Foreground Service для фонового отслеживания с типом "location".

Примечание: Поддерживается динамическая смена языка (RU/EN) и адаптация под Android 15+. Поле «Спидометр» переименовано в «Одометр» для точности.

MainViewModel

Business Logic Layer

Обрабатывает все вычисления, хранит состояние UI и синхронизирует данные между экраном и репозиторием. Поддерживает реактивное обновление при изменении дистанции.

МетодОписание
getConsumptionFactor()Рассчитывает суммарный коэффициент расхода: аддитивно прибавляет по +10% за "Зиму" и "Весну" (макс. +20%).
toggleLanguage()Переключает язык интерфейса и обновляет метки всех полей (NumericField).
onStartTrip()Сбрасывает текущий пробег, фиксирует время старта и блокирует поля ввода для защиты данных.
onStopTrip()Формирует запись о поездке (TripRecord), сохраняет её в историю и разблокирует поля.
refreshDistance()Обновляет UI-поля (спидометр, остаток топлива, средняя скорость) на основе актуальных данных от GPS.

Instruction & History Screens

UI Layer

Дополнительные экраны для повышения удобства пользователя.

  • HistoryScreen: Отображает список завершенных рейсов в обратном хронологическом порядке. Позволяет очищать историю и делиться ею.
  • InstructionScreen: Интерактивное руководство по подготовке к рейсу, управлению и интерпретации данных.

LocationService

Background Layer

Foreground Service, обеспечивающий непрерывность сбора данных. Работает в отдельном процессе от UI.

МетодОписание
updateNotification()Динамически обновляет уведомление: текущая скорость, путь, общий одометр и курс по компасу.
onLocationResult()Фильтрует GPS-шумы (точность < 50м) и суммирует дистанцию при перемещении > 3м.
onSensorChanged()Обновляет значение азимута для отображения текущего курса в шторке уведомлений.
