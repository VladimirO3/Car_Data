Документация приложения TrackLit v1.5

MainActivity & UI Enhancements

Jetpack Compose & Animation

Полностью переработанная система навигации и визуальных эффектов.

КомпонентОписание
Swipe NavigationГоризонтальный свайп на главном экране открывает внешний навигатор (Яндекс Навигатор/Карты/Google Maps) с текущими координатами.
SmokeEffectАнимированный слой дыма, появляющийся при активном рейсе. Реализован через Canvas и InfiniteTransition.
GoodbyeScreenАнимированный экран прощания с "грустным лицом", отображаемый 3 секунды перед выходом из приложения.
Theme SupportДинамическая поддержка Светлой, Темной и Системной тем оформления.

Technical Improvements

Performance
  • Edge-to-Edge: Приложение отображается под системными панелями, иконки статус-бара адаптируются под фон.
  • Cleanup: Удален тяжелый WebView, навигация перенесена во внешние приложения для экономии ресурсов.
  • Custom Vectors: Добавлена оригинальная иконка GitHub (Bootstrap style) в формате Vector Drawable.
