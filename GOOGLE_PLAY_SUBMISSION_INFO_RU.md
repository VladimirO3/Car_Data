# Информация для публикации TrackLit в Google Play

Этот файл содержит данные, необходимые для заполнения полей в Google Play Console (Store Listing, Data Safety и декларации).

---

## 1. Информация о приложении (Store Listing)

**Название приложения:** TrackLit: GPS Трекер и Расход

**Краткое описание (Short Description):**
Профессиональный GPS-трекер для записи рейсов, контроля расхода топлива и одометра.

**Полное описание (Full Description):**
TrackLit — ваш надежный помощник в дороге! Профессиональный инструмент для водителей, позволяющий точно отслеживать параметры поездки в режиме реального времени.

Основные возможности:
- 🚀 **Точный GPS-трекинг:** Повышенная точность с порогом 1 метр и разделением на Город/Межгород.
- ⛽ **Контроль топлива:** Учет расхода основного двигателя, спецоборудования и прогрева.
- 📈 **История рейсов:** Детализированный JSON-лог с возможностью ручного редактирования записей.
- 🧭 **Встроенный компас:** Поможет сориентироваться и найти обратный курс.
- 🗺️ **Быстрая навигация:** Мгновенный переход к Яндекс Навигатору или Google Maps одним свайпом.
- ❄️ **Winter Edition:** Уникальный анимированный интерфейс с эффектом дыма и зимним шаром.
- 🔒 **Приватность:** Все данные хранятся локально на вашем устройстве.

TrackLit работает в фоновом режиме, позволяя вам использовать другие приложения, пока идет запись рейса. Идеально подходит для дальнобойщиков, курьеров и автопутешественников.

## 2. Безопасность данных (Data Safety)

Вам нужно указать следующие пункты в разделе "Конфиденциальность данных":

1.  **Местоположение (Location):**
    *   **Приблизительное местоположение:** Собирается (для расчета дистанции).
    *   **Точное местоположение:** Собирается (для работы GPS-трекера).
    *   *Примечание:* Данные используются только локально для расчетов и не передаются на сервер.
2.  **Идентификаторы устройства (Device IDs):**
    *   **Идентификатор устройства или другие идентификаторы:** Собираются (используется SDK MyTracker/Firebase для аналитики и защиты от фрода).
3.  **Использование данных:**
    *   Данные **не передаются** третьим лицам (кроме анонимной аналитики).
    *   Данные **не шифруются** при передаче (так как передача на сервер разработчика отсутствует).
    *   Пользователь может запросить удаление данных (очистка истории в настройках).

## 3. Декларация о фоновом местоположении (Background Location)

Так как приложение запрашивает `ACCESS_BACKGROUND_LOCATION` для записи трека при свернутом приложении:

**Цель:** Приложение должно записывать пройденный путь и рассчитывать расход топлива, даже если водитель переключился на навигатор или выключил экран.
**Описание для Google:** "TrackLit собирает данные о местоположении для обеспечения работы GPS-трекера и расчета дистанции рейса, даже когда приложение закрыто или не используется. Эти данные необходимы для корректного ведения истории поездок и учета расхода топлива в реальном времени."

## 4. Техническая информация (Native & Symbols)

*   **Native Debug Symbols:** Файл `native-debug-symbols.zip` генерируется автоматически при сборке App Bundle.
    *   Путь после сборки: `app/build/outputs/native-debug-symbols/release/native-debug-symbols.zip`
    *   В `build.gradle.kts` включена опция `debugSymbolLevel = "full"`, что позволяет Google автоматически извлекать символы из `.aab`.
*   **Crashlytics:** Символы NDK автоматически загружаются в Firebase при выполнении задачи `uploadCrashlyticsSymbolFileRelease`.
